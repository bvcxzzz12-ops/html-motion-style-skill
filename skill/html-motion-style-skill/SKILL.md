# HTML 모션 발표 스타일

사용자의 발표 내용을 브라우저에서 넘길 수 있는 장면으로 구성한다. 사용자가 기존 HTML을 주면 그 파일의 내용, 구조와 조작 계약을 먼저 읽고 요청한 연출만 바꾼다. 새 덱은 [assets/deck.html](assets/deck.html)을 복사해 편집한다.

1. 발표 장소, 청중, 시간, 핵심 메시지를 파악한다. 이미 주어진 정보는 재질문하지 않는다. 정보가 부족하면 장면 순서나 표현을 실제로 바꿀 질문만 한다.
2. 문장과 자료를 장면으로 나눈다. 장면의 제목을 먼저 보이고 근거, 순서, 강조 문구는 말하는 흐름에 맞춰 공개한다. 사용자 자료에 없는 수치나 사실은 예제 값으로 채우지 않는다.
3. [references/style.md](references/style.md)를 참고해 글자 크기, 리본과 색, 움직임을 맞춘다. 필요하면 가장 중요한 두 장면을 먼저 만들어 전체 덱에 적용할 밀도와 강도를 확인한다.
4. 실제 브라우저에서 첫 화면, 공개가 끝난 화면, 네비게이션을 확인한다. 글자 겹침과 대비를 고치고 키보드, 화면 크기 변화, 모션 줄이기 설정에서도 발표 순서가 유지되는지 살핀다.

새 파일의 기본 출력은 외부 라이브러리를 요청하지 않는 HTML 한 개다. 사용자 자료를 별도 파일로 연결해야 하면 로컬 상대 경로로 구성한다. 결과와 함께 여는 방법과 실제 검증 범위를 알려 준다.
